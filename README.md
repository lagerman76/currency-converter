# currency-converter
Простой и удобный конвертер валют, который позволяет быстро перевести сумму из одной валюты в другую по актуальному курсу. Приложение поддерживает несколько популярных валют и автоматически обновляет курсы через открытые API. Подходит для личного использования, учебных проектов или интеграции в другие приложения.
